# 工作区目录浏览器弹窗编辑器化设计

## 背景

当前会话页里的工作区浏览器把“导航、内容预览、diff 预览、下载”揉在同一个右侧区域里，结果是：

- 新建会话或打开会话时，工作区会默认弹出，打断聊天主流程。
- 右侧区域承担了太多职责，文件内容和 diff 内容都在侧边挤压显示。
- 目录层级一次性加载，后续交互也没有按需展开的节奏。
- `AGENTS.md` 和 `skills/` 在浏览器里默认可见，内部工作区路径信息也在 UI 中暴露。

这版重构要把工作区浏览器收回成“可打开的导航面板 + 独立弹窗查看器”，让聊天主界面保持干净。

## 目标

- 新建会话或切换/打开会话时，工作区默认隐藏，不自动弹出。
- 侧栏只保留目录导航和条目列表，不再显示 diff 正文。
- 文件内容查看与 diff 查看统一进入一个大的只读编辑器弹窗。
- 弹窗使用 Monaco 这一类轻量编辑器能力，提供接近 VS Code 的阅读体验。
- 文件/`diff` 切换收缩成更紧凑的控件，风格接近现有“可写 / 只读”切换。
- 每个文件/文件夹条目都提供独立下载入口；文件夹下载为 zip。
- 默认隐藏 `AGENTS.md` 和 `skills/`，并继续隐藏现有的工作区 sidecar 文件。
- 不在 UI 中暴露后端工作区根路径。
- 如果当前目录树不是懒加载，则改成点击文件夹时再加载子目录内容。

## 设计

### 1. 工作区面板的打开逻辑

`ChatView` 仍然保留顶部工具栏里的工作区按钮，但它只负责手动打开/关闭。

- 进入会话时，工作区默认隐藏。
- 切换到其他会话时，工作区也回到隐藏状态。
- 只有用户点击按钮后，工作区面板才展开。
- 打开或关闭工作区时，不应影响当前聊天输入、消息流或其它会话状态。

### 2. 侧栏结构

工作区侧栏改成两块：

1. 左侧是目录树，只负责展开、折叠和进入目录。
2. 右侧是当前目录的条目列表，只展示文件夹、文件名、相对路径和状态标记。

右侧列表不再渲染：

- 文件正文
- diff 正文
- 后端根路径
- home/task/backup 等内部目录信息

列表里可以显示 diff 是否存在的标记，但 diff 内容必须只在弹窗里看。

### 3. 懒加载目录

目录树改成懒加载：

- 初次进入会话时，只加载根目录的可见条目。
- 用户点击某个文件夹展开时，才请求该目录的子内容。
- 子目录数据要缓存，折叠后再次展开不重复拉取。
- 当前目录的右侧列表跟随被选中的目录更新。

这样可以避免一次性拉满整棵树，也让大工作区更轻快。

### 4. 弹窗查看器

文件内容与 diff 内容统一使用一个大弹窗承载，弹窗采用 Teleport 到 `body` 的方式。

弹窗要求：

- 上下各留约 `10vh` 间距。
- 宽度随视口伸缩，但保持接近大屏阅读体验。
- 弹窗内部独立滚动，外层不滚页面。
- 点击遮罩或按 `Esc` 关闭。
- 打开时只显示当前文件的相对路径，不显示后端真实根路径。

查看器内部使用 Monaco 类编辑器：

- 文件模式用只读编辑器。
- diff 模式用只读 diff 视图。
- 顶部的文件 / Diff 切换收缩成更紧凑的 segmented / pill 控件。
- 切换状态要像现有“可写 / 只读”切换一样紧凑，避免大面积占位。

二进制文件不走文本编辑器，改为显示简短元信息和下载入口。

### 5. 下载规则

下载能力保留在条目级别，不再依赖右侧预览区。

- 文件条目下载：沿用现有单文件下载语义。
- 文件夹条目下载：返回 zip。
- zip 内容只打包当前浏览器可见的条目，保持目录结构相对路径一致。
- `AGENTS.md`、`skills/` 和现有 sidecar 文件不进入列表，也不进入 zip。

下载接口可以继续复用现有 workspace download 路径，只是需要让目录路径返回 zip 语义。

### 6. 隐藏规则

工作区浏览器必须默认隐藏这些内容：

- `AGENTS.md`
- `skills/` 目录及其所有子内容
- 现有工作区 sidecar 文件

这条规则要同时影响：

- 目录树
- 右侧条目列表
- 文件 / diff 查看入口
- 文件夹 zip 下载

也就是说，浏览器只展示用户能自然操作的内容，不把内部工作区实现细节露出来。

### 7. 搜索

搜索能力可以保留，但只作用于当前已经加载到客户端的数据。

- 已展开目录和当前目录列表可以被搜索过滤。
- 未加载的目录不会为了搜索被提前递归拉取。

这样能保住交互简单性，不把懒加载又拉回全量扫描。

## 非目标

- 不新增独立的工作区管理页面。
- 不把工作区改成可编辑模式。
- 不改聊天之外的任务/审批/交互主流程。
- 不新增第二套 workspace 配置源。
- 不把后端绝对路径暴露给前端用户。

## 验收标准

- 新建会话或打开会话时，工作区默认隐藏。
- 用户不手动点击时，工作区不会自动弹出。
- 侧栏不再显示 diff 正文。
- 文件和 diff 都能在大弹窗里通过 Monaco 类编辑器查看。
- 文件/Diff 切换明显变小，更像紧凑的模式切换，而不是大页签。
- 文件夹可以下载 zip，文件可以正常下载原文件。
- `AGENTS.md` 和 `skills/` 默认不出现在浏览器里。
- UI 中不出现 `home_root`、`task_root` 之类后端根路径。
- 文件夹展开时按需加载子目录，不再一次性灌满整棵树。
